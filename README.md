# FILUM — The Living Filament

Cinematic WebGL concept landing page for a fictional private treasury.
A single filament of golden light evolves through six chapters as you scroll:
Introduction → Momentum → The System → Instruments → Security → Access.

**Stack:** Three.js (custom GLSL ribbons, bloom, anamorphic streaks), GSAP + ScrollTrigger, Lenis smooth scroll. One self-contained `index.html`, libraries from CDN.

Design & art direction: Marta Jakovleva. A design concept — FILUM is not a real company.
